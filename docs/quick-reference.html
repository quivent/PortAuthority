⚓ Porter Quick Reference

Subdomain-to-Port Mapping Made Simple

🚀 Quick Start

# 1. Set your base domain
porter set base localhost

# 2. Map a subdomain to a port
sudo porter map api 3000

# 3. Open in browser
porter open api

# Opens: http://api.localhost:3000

📋 Command Reference

Configuration

Command Description Example
porter set base <domain> Set the base domain for all mappings porter set base localhost

Subdomain Mapping

Command Description Example
porter map <subdomain> <port> Map a subdomain to a port sudo porter map api 3000
porter route <subdomain> <port> Alias for map sudo porter route web 8080
porter unmap <subdomain> Remove a mapping sudo porter unmap api
porter list Show all current mappings porter list

Browser Integration

Command Description Example
porter open <subdomain> Open mapped URL in browser porter open api

Utilities

Command Description Example
porter tree [depth] Display command hierarchy porter tree 2
porter docs Open documentation in browser porter docs
porter reset [--yes] Clear all configuration porter reset --yes
porter --verbose <cmd> Run with debug logging porter --verbose list
porter --help Show help information porter --help

💡 Common Usage Patterns

Development Environment Setup

# Set up local development domains
porter set base localhost

# Frontend
sudo porter map app 3000

# Backend API
sudo porter map api 8080

# Admin panel
sudo porter map admin 4000

# List all mappings
porter list

# Open services
porter open app
porter open api

Multiple Projects

# Project A
sudo porter map project-a 3000

# Project B
sudo porter map project-b 3001

# Microservices
sudo porter map auth 4000
sudo porter map users 4001
sudo porter map payments 4002

⚠️ Important Notes

Permissions: Modifying the hosts file requires elevated permissions.
  • macOS/Linux: Use sudo before map/unmap commands
  • Windows: Run terminal as Administrator
Pro Tip: Porter automatically backs up your hosts file before making changes. Backups are stored safely so you can always recover if needed.

📁 Configuration

Porter stores configuration in ~/.porter/config.toml:

[base]
domain = "localhost"

[mappings]
api = 3000
web = 8080
admin = 4000

🔍 Troubleshooting

Mapping Not Working

  1. Check configuration: porter list
  2. Verify hosts file: cat /etc/hosts (macOS/Linux)
  3. Clear browser cache
  4. Try verbose mode: porter --verbose map api 3000

Permission Denied

Run with sudo (macOS/Linux) or as Administrator (Windows)

Browser Not Opening

Porter will print the URL even if browser fails to open. Copy and paste the URL manually.
